\# 🧬 Pheflux SaaS



Plataforma web orientada a la modelación de rutas metabólicas integrando datos transcriptómicos, con enfoque en análisis sistémico y visualización interactiva.



> ⚠️ Este repositorio corresponde a una versión conceptual/demostrativa del proyecto.



\---



\## 🎥 Demo



👉 \[Ver demo](docs/demo.mp4)



\---



\## 🚀 Descripción



Pheflux fue concebido como una solución SaaS para:



\- Integración de datos transcriptómicos  

\- Modelación de flujos metabólicos  

\- Visualización de rutas  

\- Interacción con modelos biológicos desde web  



\---



\## 🧠 Enfoque técnico



\- Backend: Python (modelación y procesamiento)  

\- Frontend: interfaz web interactiva  

\- Base de datos: datasets biológicos
